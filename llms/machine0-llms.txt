## Docs

- [Account](https://docs.machine0.io/cli/account.md): CLI reference for authentication, billing, and configuration.
- [Disks](https://docs.machine0.io/cli/disks.md): CLI reference for creating, inspecting, listing, and removing persistent disks (experimental).
- [Env Sets](https://docs.machine0.io/cli/env.md): CLI reference for managing environment variable sets.

- [SSH Keys](https://docs.machine0.io/cli/keys.md): CLI reference for managing SSH keys.
- [Machines](https://docs.machine0.io/cli/machines.md): CLI reference for creating, managing, and connecting to VMs.
- [CLI](https://docs.machine0.io/cli/overview.md)
- [Profiles](https://docs.machine0.io/cli/profiles.md): CLI reference for profiles — named groups of integrations (Claude Code, Codex, GitHub, remote MCP servers), prompts, and env variables, each with its own MCP endpoint.
- [Prompts](https://docs.machine0.io/cli/prompts.md): CLI reference for prompts — named text templates stored on a profile and served over its MCP endpoint as slash commands.
- [Sync](https://docs.machine0.io/cli/sync.md): CLI reference for syncing files between your local machine and VMs.
- [Profile variables](https://docs.machine0.io/cli/vars.md): CLI reference for vars — env variables stored on a profile and injected into every VM created with it, with optional write-only secrets.
